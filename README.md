# Heaven Manager

برنامج سطح مكتب (Windows و Mac) لإدارة **Heaven** — لوكيشن تصوير العرائس:
حجوزات العرائس، تذاكر الدخول، الكافيه، وكل الحسابات الداخلة والطالعة.

- يشتغل **أوفلاين** بالكامل — البيانات محفوظة على الجهاز.
- لما النت يكون موجود، **بيتزامن أونلاين** بين كل الأجهزة (Supabase مجاني).
- واجهتين: **المدير** و**الموظف**.

## المميزات

| القسم | المدير | الموظف |
|---|---|---|
| الحجوزات (تقويم، باكدجات، إضافات، عربون ومتبقي، إيصال) | ✔ | ✔ |
| تعديل سعر الحجز / عمل خصم | ✔ | لو المدير سمح |
| تذاكر الدخول (بيع وطباعة) | ✔ | ✔ |
| تعديل أسعار التذاكر | ✔ | ✖ |
| الكافيه: كاشير بمنيو + حسابات الكافيه (إيرادات ومصروفات) | ✔ | ✔ |
| تعديل المنيو والأسعار | ✔ | ✖ |
| تسجيل مصروفات | ✔ | لو المدير سمح |
| الحسابات الكاملة والأرباح والتقارير وتصدير Excel | ✔ | ✖ (يشوف عملياته بس للتقفيل) |
| حذف أي عملية | ✔ | ✖ |
| المستخدمين، الصلاحيات، المزامنة، النسخ الاحتياطي | ✔ | ✖ |

**طرق تسعير الحجز (يحددها المدير من الإعدادات ← الباكدجات):**
- **سعر ثابت**: باكدج بمدة وسعر محددين (مثلاً سيشن ساعتين = 2500).
- **بالساعة**: سعر الساعة × عدد الساعات.
- **سعر يدوي**: الموظف يكتب السعر المتفق عليه.
- بالإضافة لـ **إضافات** (ساعة إضافية، الروم…) و**خصم** و**تعديل السعر النهائي** حسب صلاحيات الموظف.

## التشغيل لأول مرة

1. ابني ملف التسطيب على الجهاز نفسه (محتاج Node.js مثبت):
   - على الماك: `npm install` ثم `npm run dist:mac` ← ملف `.dmg` في فولدر `release`.
   - على ويندوز: `npm install` ثم `npm run dist:win` ← ملف `.exe` في فولدر `release`.
2. ادخل بـ `admin` / `admin` وغيّر كلمة المرور فوراً من **حسابي**.
3. من **الإعدادات** ظبط الباكدجات وأسعار التذاكر والمنيو، واعمل حسابات للموظفين.

> **على الماك:** لأن البرنامج غير موقّع من Apple، أول مرة اعمل كليك يمين على البرنامج ← Open.
> لو ظهرت رسالة إن البرنامج "تالف"، افتح Terminal واكتب:
> `xattr -cr "/Applications/Heaven Manager.app"`

## تفعيل المزامنة الأونلاين (مرة واحدة)

1. اعمل حساب مجاني على [supabase.com](https://supabase.com) واعمل مشروع جديد.
2. من **SQL Editor** الصق محتوى الملف [`supabase/schema.sql`](supabase/schema.sql) (أو من داخل البرنامج: الإعدادات ← المزامنة ← زرار "نسخ كود SQL") واضغط **Run**.
3. من **Authentication ← Users ← Add user** اعمل إيميل وكلمة مرور للمكان (فعّل Auto Confirm).
4. من **Project Settings ← API** انسخ `Project URL` و `anon public key`.
5. على **كل جهاز**: الإعدادات ← المزامنة الأونلاين ← اكتب البيانات ← حفظ واتصال.

كل جهاز بيشتغل عادي من غير نت، وأول ما النت يرجع بيرفع التعديلات ويستقبل تعديلات باقي الأجهزة تلقائياً (كل 20 ثانية).
لو نفس السجل اتعدل على جهازين، **آخر تعديل هو اللي بيتحفظ**.

## المستخدمين والصلاحيات

- **الأدوار:** مدير (كل حاجة)، موظف (قابل للتعديل)، وتقدر تعمل أدوار جديدة زي "كاشير" أو "استقبال" من الإعدادات ← الصلاحيات.
- **31 صلاحية** مقسمة على: الحجوزات، التذاكر، الكافيه، الحسابات، الإدارة. كل صلاحية بتتحقق في البرنامج نفسه مش في الواجهة بس.
- محدش يقدر يدي صلاحية مش عنده، ولا يغير دوره بنفسه.
- **سجل النشاط:** مين أضاف أو عدّل أو حذف إيه ومتى.

### حساب المطور (الدعم الفني)
- الدخول: `developer` / `developer` — **غيّر كلمة المرور أول مرة**.
- عنده كل الصلاحيات + **أدوات المطور**: معلومات النظام، عدد السجلات، DevTools، إعادة المزامنة، ضغط قاعدة البيانات، تصدير ملف تشخيص.
- ظاهر للمدير في قائمة المستخدمين كـ"حساب الدعم الفني"، والمدير يقدر **يوقفه** في أي وقت لكن مايقدرش يحذفه أو يغير كلمة مروره.

## البيع: ترخيص شراء أو اشتراك شهري

البرنامج بيتباع بطريقتين، وكل عميل بياخد **مفتاح ترخيص** موقّع رقمياً (محدش يقدر يزوّره أو يغيّر تاريخه، وبيشتغل من غير نت):

| | شراء نهائي | اشتراك شهري |
|---|---|---|
| المدة | دائم | لحد تاريخ معين |
| قبل الانتهاء بـ 7 أيام | — | تنبيه في البرنامج |
| بعد الانتهاء | — | 5 أيام سماح، بعدها **للعرض فقط** (يقدر يشوف كل حاجة بس مايسجلش جديد) |
| الدعم والتحديثات | لحد تاريخ متفق عليه، ويتجدد بفلوس | جوه الاشتراك |

- من غير مفتاح: **14 يوم تجربة**.
- العميل يفعّل من: الإعدادات ← الترخيص ← يلصق المفتاح. المفتاح بيوصل لكل أجهزة المكان مع المزامنة.
- تغيير ساعة الكمبيوتر لورا مش بيطوّل الاشتراك.
- اسم المكان واللوجو والسطر اللي تحته بيتغيروا من الإعدادات ← عام، فنفس البرنامج يتباع لأي مكان.

### برنامج إدارة العملاء (ليك انت بس)

```bash
npm run vendor
```

- **نظرة عامة:** العملاء الشغالين، الدخل الشهري المتكرر، المحصّل الشهر ده، ومين محتاج تجديد، ورسم الدخل لآخر 12 شهر.
- **العملاء:** الباقة، السعر، **باقي كام يوم**، آخر دفعة، فلاتر (ينتهي قريب / فترة سماح / منتهي / شراء نهائي…).
- **تجديد:** تختار المدة (شهر / 3 / 6 / سنة بسعر 10 شهور)، يتسجل المبلغ، ويطلع المفتاح الجديد بزرار **إرسال واتساب**.
- **المدفوعات** وتصديرها Excel، و**الباقات والأسعار**.

**أول مرة (مهم):**
1. شغّل `npm run vendor` ← الإعدادات ← **اربط البرنامج بالمفتاح ده**. ده بيكتب `electron/license-public.cjs`.
2. اعمل commit للملف ده، وبعدين build جديد للبرنامج اللي بتسلّمه للعملاء.
3. خد **نسخة احتياطية** من الإعدادات واحفظها برا الجهاز. فيها المفتاح السري — لو ضاع، مش هتقدر تطلّع مفاتيح للنسخ اللي اتسلّمت.

> طول ما `license-public.cjs` فاضي (`null`)، نظام الترخيص مقفول والبرنامج شغال من غير قيود.
> المفتاح السري **مايترفعش على GitHub أبداً** — هو محفوظ في فولدر بيانات برنامج الإدارة بس.

## نسخة تجريبية ببيانات كتير (للتجربة)

```bash
npm run demo        # يعمل بيانات سنة كاملة (~20 ألف عملية) ويفتح البرنامج
npm run demo:open   # يفتح النسخة التجريبية تاني من غير ما يعيد البيانات
```

- البيانات بتتحفظ في فولدر `demo-data` جوه المشروع، **منفصلة تماماً** عن بياناتك الحقيقية، ومش بتتزامن أونلاين.
- الدخول: `admin`/`admin` — `developer`/`developer` (مطور) — `sara`/`1234` (موظف) — `karim`/`1234` (كاشير) — `abdo`/`1234` (اسم طويل) — `mariam`/`1234` (مدير).
- تقدر تشغلها جنب البرنامج العادي في نفس الوقت. لمسحها: امسح فولدر `demo-data`.

## النسخ الاحتياطي

الإعدادات ← النسخ الاحتياطي ← حفظ نسخة احتياطية (ملف JSON).
يُنصح بعمل نسخة أسبوعياً على فلاشة أو Google Drive حتى لو المزامنة شغالة.

## للمطورين

```bash
npm install
npm run dev        # تشغيل للتطوير (Vite + Electron)
npm test           # اختبارات قاعدة البيانات والصلاحيات والمزامنة
npm run dist:win   # بناء ملف التسطيب لويندوز (على جهاز ويندوز)
npm run dist:mac   # بناء ملف التسطيب للماك (على جهاز ماك)
```

ملفات التسطيب بتتبني على جهاز بنفس نظام التشغيل (ماك للماك، ويندوز للويندوز).

**التقنيات:** Electron + React (Vite) + SQLite المدمج في Electron (`node:sqlite`) — من غير أي مكتبات native، فالبناء لويندوز وماك سهل.

**هيكل المشروع:**

```
electron/
  main.cjs      نافذة البرنامج وقنوات IPC
  store.cjs     قاعدة البيانات المحلية (SQLite) — كل سجل JSON مع updated_at للمزامنة
  service.cjs   تسجيل الدخول والصلاحيات والبيانات الافتراضية
  sync.cjs      المزامنة مع Supabase (رفع واستقبال، آخر تعديل يكسب)
src/
  pages/        الشاشات: الرئيسية، الحجوزات، التذاكر، الكافيه، الحسابات، الإعدادات
  lib/          الحسابات والتنسيق والطباعة
supabase/schema.sql   جدول السيرفر ودالة الرفع
test/                 اختبارات
```

البيانات المحلية محفوظة في:
- Windows: `%APPDATA%\Heaven Manager\heaven.db`
- Mac: `~/Library/Application Support/Heaven Manager/heaven.db`
